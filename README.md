#### 🛒 [Masqchuches Online](https://github.com/JavierMolero12) — eCommerce Premium & Transformación Digital
Desarrollo integral de una plataforma de comercio electrónico de alto rendimiento optimizada para la digitalización completa de un negocio familiar de dulces y regalos personalizados.
* **Stack Técnico:** Next.js 15+, React.js, Tailwind CSS, Framer Motion, PostgreSQL, Drizzle ORM, Stripe, Auth.js, AWS S3, Resend.
* **Hitos Clave:** * Implementación de arquitectura moderna con App Router para maximizar la velocidad de carga y el SEO.
  * Modelado de base de datos relacional y optimización de consultas complejas para garantizar la escalabilidad del sistema.
  * Integración segura de pasarela de pagos (Stripe), gestión de imágenes en la nube (AWS S3) y sistema de autenticación robusto.

#### 👁️ [Aplicación de Clasificación y Descripción de Imágenes](https://github.com/JavierMolero12) — API de IA en Tiempo Real
Sistema avanzado de análisis visual y procesamiento del lenguaje natural (NLP) orientado al procesamiento y descripción de flujos de vídeo y cámaras en tiempo real.
* **Stack Técnico:** FastAPI, PyTorch, Transformers (Hugging Face), Ultralytics (YOLO), Ollama, ChromaDB.
* **Hitos Clave:**
  * Diseño de una API REST asíncrona de alto rendimiento con FastAPI para análisis de imágenes bajo demanda.
  * Integración de modelos YOLO para tareas precisas de detección, localización y clasificación de objetos visuales.
  * Construcción de un sistema de búsqueda semántica e indexación visual basado en la base de datos vectorial ChromaDB.
  * Despliegue y ejecución de LLMs en local a través de Ollama para generar descripciones contextuales fluidas y automatizadas.
